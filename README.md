# 🔮 Astrology Reading App

A lightweight, interactive web application that generates personalized astrology readings, compliments, recommendations, and predictions based on user birth details.

Built as a probation project for my web development society submission.

---

## 🌟 Features

- **User Input Form:** Collects user's first name, surname, birth day, birth month, and birth year with built-in HTML5 form validation.
- **Dynamic Astrological Logic:** Calculates zodiac signs and personalized readings using array indexing and basic mathematical operations.
- **Clean UI:** Styled with simple, modern CSS focused on readability and user experience.
- **DOM Manipulation:** Updates reading results instantly without reloading the page.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structural elements and form validation attributes (`min`, `max`, `required`).
- **CSS3:** Flexbox layout, soft shadow cards, and responsive styling.
- **JavaScript (ES6):** Event listeners, form handling, DOM manipulation, and dynamic array calculations.
